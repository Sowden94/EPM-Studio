# Changelog

## Unreleased beta — 6 November 2026

- Side-by-side molecule drawing and EPM workspace, with a wider drawing panel and larger viewer.
- Organic chemistry drawing controls, formal charges, wedge/dash bonds, and an Other atoms selector.
- Local Gasteiger point-charge estimates for new drawings, with explicit method and surface labels.
- Six demand-loaded RHF/6-31G* quantum examples and matching cube-data imports.
- Rainbow and alternative potential palettes, opacity controls, centred atom labels and carbon labels enabled by default.
- PNG, looping GIF and supported WebM rotation exports with method and scale captions.
- Drawing-only molecule input; image upload, paste and recognition controls removed from the beta.
- GitHub Pages beta badge, prominent live-site README link, method documentation and automated checks.
- GitHub feature README, GPL-3.0-only licence, third-party notices and repository guidance.

No GitHub release or desktop build is implied by this entry. Hosting and release publication are controlled by the repository owner.
