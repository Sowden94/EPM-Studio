Browser-estimated electrostatic potential

The browser calculation is an empirical point-charge estimate, displayed on a smoothed van der Waals surface. It is distinct from the quantum-derived electrostatic potential mapped onto electron density in the supplied examples.

Calculation

  1. Read the drawn atoms, bond orders, formal charges and wedge/dash stereochemistry with OpenChemLib 9.25.2.
  2. Generate one seeded 3D conformer with explicit hydrogens. Refine it using MMFF94 when supported; the calculation record states whether minimisation succeeded. No conformational ensemble or solvent is modelled.
  3. Compute Gasteiger–Marsili atomic charges with 12 equalisation iterations, using parameters and an adapted algorithm from RDKit. The JavaScript implementation is checked against RDKit reference charges for a range of organic examples, including F, Cl, Br and I. Hybridisation and conjugation perception use OpenChemLib and can differ from RDKit for other chemical environments.
  4. Build a smooth union of atom-centred van der Waals spheres. This display surface is not computed electron density. Radii use Bondi values for H, C, N, O, F, Si, P, S, Cl, Br and I; B uses the Mantina et al. value.
  5. Evaluate V(r) = Σ qᵢ / |r − Rᵢ|, with distances in bohr and charges in units of e. Potential units are hartree/e. Values beyond the selected display scale are clipped to the end colours.

Interpretation and limits

Use this mode for qualitative polarity demonstrations. Atom-centred charges omit anisotropic electron density, lone-pair directionality, halogen σ-holes and electronic polarisation. They cannot be relied upon to predict halogen bonding, reaction selectivity or quantitative interaction energies. Charged, unusual-valence and delocalised structures require particular care. A single generated conformer is not necessarily the global minimum.

The current size limit is 40 non-hydrogen atoms and 180 atoms after hydrogen addition. Unsupported parameters, disconnected structures, invalid geometries and non-finite values produce an error rather than a substitute map. A calculation is stopped after 60 seconds. This does not guarantee every structure within the size limit will succeed.

Privacy

The drawn molecule, generated coordinates, charges and estimated surface stay in your browser. The chemistry engine is downloaded as a website asset. This beta uses drawing-only molecule input. Image upload and recognition are not available.
