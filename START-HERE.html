SETUP GUIDE · 6 NOVEMBER 2026

Put EPM Studio under your control

You create your own GitHub repository and hosting project. This package contains the latest carbon labels, browser EPM estimates, lecture exports, six quantum examples and the optional image-recognition endpoint.

Recommended: GitHub stores your code; Cloudflare Pages publishes the site from your repository. This keeps automatic image recognition. EPM estimates still run entirely in the browser.

1. Create your GitHub repository

  1. Unzip the download and open the extracted EPM-Studio-GitHub folder.
  2. At GitHub, choose + → New repository. Name it EPM-Studio. A private repository can be connected to Cloudflare Pages.
  3. Create the repository. Adding a temporary README makes the upload menu easier to find.
  4. Choose Add file → Upload files. Drag in the contents of the extracted folder, including its subfolders, then commit to main.
  5. Check docs/index.html and functions/api/recognize.js exist at those exact paths. Upload extracted files, not the ZIP or an extra enclosing folder.

2. Publish using Cloudflare Pages

  1. Open your own Cloudflare dashboard, then Workers & Pages → Create application. Choose the Pages / Connect to Git route.
  2. Connect GitHub and select your new repository.
  3. Enter the settings below, then select Save and Deploy.

Open the finished URL Cloudflare displays. Keep functions and server at the repository root, outside docs. Use the Git connection: dashboard ZIP uploads do not deploy the Functions folder.

3. Test it

  • Draw C–Cl and choose Show potential map. Look for CH3Cl · estimated EPM.
  • Check carbon labels, rotation, PNG and GIF downloads.
  • Load a computed example and check the RHF/6-31G* badge.
  • Choose Upload image → Recognise molecule, then review the returned editable drawing.

Using GitHub Pages alone

You can instead choose Repository Settings → Pages → Deploy from a branch → main → /docs → Save. This runs drawing, local EPM generation, examples and exports. It does not run automatic image recognition; the upload panel explains that limitation. Keep the supplied docs/.nojekyll file; see SETUP.md if your upload omitted it.

Updating your site

Commit changes to your repository's main branch. Your chosen host republishes the site. Check deployment success, then hard-refresh the website. Use the new host's URL rather than the old ChatGPT demo.

A private repository does not make the website private. The resulting site is public unless you separately add access protection. No ChatGPT sign-in or credentials are included in this export.

What stays local?

Drawn structures and browser EPM calculations stay on the visitor's device. Choosing Recognise molecule sends the selected image to the external DECIMER service. Browser maps are Gasteiger point-charge estimates on a van der Waals surface, with a 40 non-hydrogen atom limit. They do not capture halogen sigma-holes or full quantum electron density.
